### 🔨 Currently building

- **[Coral-C5](https://github.com/SmallCoral/Coral-C5)** — A modular STM32C5A3 board family with a core board, an expansion board, and a dual-motor robotics expansion. Core PCB DRC is clean; expansion-board work is ongoing.
- **[Coral-Wave](https://github.com/SmallCoral/Coral-Wave)** — A USB audio interface using ATSAMD21E18A and WM8978, with a Windows control utility. Playback and microphone capture have been tested on hardware at 48 kHz.
- **FPGA Robot** — A camera → DDR3 → 480 × 272 TFT video pipeline, with Ethernet debugging and LD06 LiDAR obstacle avoidance in development.
- **CMSIS-DAP v2 Debug Probe** — A compact STM32F042 SWD probe, with USB enumeration and OpenOCD connectivity tested.
